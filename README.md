

## Features

- Secure online payment processing via NovaPay
- Native integration with PrestaShop
- Fast and simple setup
- Designed for e-commerce checkout scenarios


## Requirements

- PrestaShop 1.6 – 1.7
- Valid NovaPay merchant account

---

## Quick Start

1. Install the module
2. Add your NovaPay credentials
3. Enable the payment method
4. Start accepting payments

---

## Installation

1. Download the module from this repository
2. Upload the module to your PrestaShop installation
3. Go to **Modules → Module Manager**
4. Find **NovaPay** and install it
5. Open module settings
6. Enter your NovaPay credentials
7. Enable the module

---

## Configuration

Configure the following parameters:

- Merchant credentials
- API access settings
- Payment status
- Additional integration parameters
